# starlock · 星辰超级岛

将小米手机**应用锁**的解锁动画迁移到 HyperOS **超级岛**（焦点通知）上展示。

当你打开已加锁的应用时，解锁过程中的「正在解锁 → 解锁成功 / 解锁失败」状态会以超级岛动画的形式呈现，替代系统默认的弹窗提示。

---

## ✨ 功能

- 🎯 **认证中**：超级岛显示「正在解锁 · 应用锁验证中…」
- ✅ **解锁成功**：超级岛显示「已解锁 \<应用名\> · 应用锁已解除」（绿色高亮）
- ❌ **解锁失败**：超级岛显示「解锁失败」（红色高亮）
- 🛡️ 去重机制：同一轮验证只发一次通知，避免动画不跟手
- ⏱️ 宽限机制：解锁页退出后保留 800ms，防止操作太快导致成功状态被提前撤销
- 🧪 内置「测试超级岛」按钮，无需真实解锁即可验证链路

## 📦 安装

### 1. 下载 APK

从 [Releases](https://github.com/yanyan0611/starlock/releases) 下载最新的 `AppLockIsland-release.apk`。

### 2. 安装 APK

像普通应用一样安装即可。安装后在应用列表里会出现 **starlock**（设置界面）。

### 3. 在 LSPosed 中启用模块

1. 打开 **LSPosed 管理器**
2. 进入「模块」→ 找到 **starlock** → 打开开关
3. **勾选作用域**（必须全部勾选）：
   - ✅ `com.android.systemui`（系统界面）
   - ✅ `com.miui.securitycenter`（安全中心）
   - ✅ `com.xiaomi.xmsf`（小米服务框架）
   - ✅ `com.applockisland`（模块自身）

### 4. 重启设备

作用域勾选完成后，**重启手机**使模块生效。

## 🚀 使用

1. 打开 **starlock** 应用，可以看到以下开关：
   - **启用应用锁超级岛**：总开关（默认开启）
   - **显示成功动画**：解锁成功时在超级岛展示成功状态
   - **隐藏原始解锁弹窗**：尝试隐藏系统默认验证界面（实验性）
   - **成功状态持续显示**：解锁成功后保持显示直到超时收起

2. 点击 **测试超级岛** 按钮，可以立即向超级岛发送一条测试通知，验证模块链路是否正常。

3. 打开任意一个**已加锁**的应用，解锁时顶部超级岛会出现相应动画。

## ⚙️ 工作原理

模块通过 LSPosed Hook 以下进程实现功能：

| 进程 | Hook 内容 |
|------|-----------|
| `com.miui.securitycenter` | 监听应用锁 Activity 生命周期（onResume/onPause）及生物识别认证调用 |
| `com.android.systemui` | 接收认证状态，通过 `miui.focus.param` 构建超级岛焦点通知 |
| `com.xiaomi.xmsf` | 绕过小米焦点通知签名校验，使第三方通知能在超级岛展示 |

认证状态流转：

```
onResume(应用锁启动) → onAuthenticating(认证中)
                      → onSuccess(解锁成功) / onFailed(解锁失败)
                      → onPause(退出)
```

## ❓ 常见问题

**Q：超级岛没有反应？**
- 确认 LSPosed 中四个作用域都已勾选
- 确认已重启设备
- 打开模块内的「测试超级岛」按钮，看是否有通知出现

**Q：动画偶尔不出现？**
- v1.0.1 已修复 `onAuthenticating` 重复触发和快速操作导致的状态丢失问题
- 如仍有问题，请抓取 LSPosed 日志反馈

**Q：解锁时仍然有系统默认的灰色方块？**
- 该方块由系统 FOD 浮窗绘制，模块不做拦截（保持系统原生体验）
